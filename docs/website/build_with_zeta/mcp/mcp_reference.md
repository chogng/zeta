# 通过 MCP 将 Zeta 连接到工具系统
了解如何使用模型上下文协议将 Zeta 连接到您的工具系统。

Zeta 可以通过模型上下文协议(MCP)接入数百种外部工具和数据源，MCP是一种用于AI工具集成的开源标准。MCP 服务器使 Zeta 能够访问您的个人工具，数据库和API。

当您需要将数据从其他工具（例如问题跟踪器或监控）复制到聊天窗口时，请连接服务器。连接后，Zeta可以直接读取并处理该系统中的数据，而无需依赖您粘贴的内容。

如果您是首次连接服务器，请先参阅[MCP 快速入门指南]()，其中包含分步说明。本页面提供完整参考信息。
