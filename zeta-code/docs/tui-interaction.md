# Zeta Code TUI 交互语义

> 状态：Current interaction contract；“推广范围与待统一项”单独记录 Proposed 设计，不代表已实现快捷键。
> 本文拥有焦点、键盘、鼠标和退出语义；[布局文档](LAYOUT.md)拥有页面部位与高度，[样式文档](styles.md)拥有字符和颜色，[TUI 架构](tui.md)拥有状态与事件边界，[crate README](../tui/README.md)记录实现入口。

## 快速理解

按键由当前操作上下文解释。先看焦点在输入框、列表还是阅读区，再判断按键做什么；不能因为界面叫“面板”就给它统一的字母命令。布局上的浮层和输入上的独占是两个独立概念。

| 当前正在做什么 | 字母如何处理 | 退出原则 |
| --- | --- | --- |
| 写消息、搜索、编辑设置 | 输入文字 | 结束当前编辑；不同时操作背景列表 |
| 选择会话或列表条目 | 执行该列表明确提供的动作，其余字符不写进草稿 | 回到进入前的界面或输入区域 |
| 阅读预览或详情 | 滚动与阅读动作，不编辑内容 | 关闭当前阅读界面并恢复返回位置 |
| 录制快捷键 | 字母和组合键都是待录制数据 | 取消录制并返回设置列表 |
| 回答提问或审批 | 明确选择并提交 | 待处理请求必须有明确结果；Esc 不代替回答或拒绝 |

统一的是输入归属、焦点表达和返回规则；具体动作仍取决于对象。Enter 在普通会话上打开，在归档会话上恢复；Space 在会话列表上预览，在多选列表上可以切换选择。操作提示必须与当前动作一致。

## 按键上下文

上下文由页面、活动组件和组件内部焦点共同决定。命令面板可以在页签、搜索框、列表和编辑框之间切换；从列表进入搜索时，字符解释立即变成文字输入。无需额外建立一个跨页面的 Normal / Insert 模式；输入框自身已有的编辑模式仍由输入框负责。

“独占输入”表示当前交互先解释事件，并阻止无效按键误触背景。它不要求铺满终端，也不要求覆盖背景。详情浮层、Session 预览和命令面板都可以独占按键；输入补全则属于输入组件的编辑上下文，候选导航不能把普通文字变成命令。

当前应用先处理详情浮层、会话预览和已聚焦的管理列表，再处理待回答请求、命令面板与 Queue；其后才经过适用的应用快捷键、页面导航和输入组件。具体可用快捷键以各上下文的处理器为准，不能声称应用快捷键在任意面板内都能穿透执行。实现入口是 [`App::handle_key_at_in_area`](../tui/src/app/state.rs)。

### 当前面板和焦点行为

下表记录当前实现。普通字母动作只对表中明确支持它的上下文生效；没有列出的 `j` / `k`、`/`、`q` 不应被当成已有能力。

| 上下文 | 当前按键与字符行为 | Esc 的结果 |
| --- | --- | --- |
| ChatInput 与输入补全 | 字符编辑草稿；输入组件解释候选导航和确认 | 按输入与补全的当前状态退出；不自动清空草稿 |
| 命令面板的列表 | 上下选择，Home/End 首尾，Enter 执行动作；Space 仅在面板启用时确认；普通字母不自动搜索 | 关闭命令面板 |
| 命令面板的页签 | Tab/Shift+Tab 切换；页签有焦点时左右切换 | 关闭命令面板 |
| 命令面板的搜索框 | 字符与粘贴编辑查询；列表顶部向上可进入搜索，有页签时从页签向下可进入搜索，也可点击搜索框 | 当前直接关闭面板，不单独返回列表 |
| Config 的文本编辑 | 字符编辑字段，Enter 提交 | 取消本次编辑，返回设置列表 |
| Keymap 的快捷键录制 | 捕获一次按键或两段组合键，包括普通字母；不执行对应业务命令 | 取消录制，返回快捷键列表 |
| Status 面板 | 上下、PageUp/PageDown、Home/End 滚动；Tab/Shift+Tab 切页，各页保留滚动位置 | 关闭面板 |
| Session 管理列表 | 上下移动；会话动作见下表；字符不写入背景草稿 | 焦点回到输入框 |
| Session 页面预览 | 方向键、PageUp/PageDown、Home/End 和滚轮滚动；`j` / `k` 与下 / 上方向键同义；不接收编辑和粘贴 | 关闭预览并回到原管理列表 |
| 详情浮层 | 上下、PageUp/PageDown 滚动，Ctrl+Home/Ctrl+End 首尾；其余按键被消费 | 关闭浮层并恢复原上下文 |
| Queue | 上下选择，Enter 恢复编辑，Ctrl+Enter 发送，Ctrl+Up/Down 调序，Delete 删除 | 焦点回到 ChatInput |
| Agents 区 | 方向键导航，Enter 确认查看的 Thread | 焦点回到 ChatInput |
| 审批和提问的选项 | 上下选择，Enter 明确提交；提交中不能重复提交 | 保持待处理状态，不隐式拒绝或回答 |
| 提问的自定义回答 | 字符与粘贴输入答案，Enter 确认 | 取消自定义输入并回到问题选项 |

### Session 管理列表的动作

| 当前项 | Enter | Space | 其他动作 |
| --- | --- | --- | --- |
| 普通会话 | 打开会话 | 打开只读会话预览 | Ctrl+X 归档，`i` 查看元数据详情，`p` 置顶或取消置顶 |
| Archived 分组标题 | 切换展开与收起 | 切换展开与收起 | 左收起、右展开；鼠标点击与键盘切换相同 |
| 归档会话 | 取消归档，保留管理页面 | 打开只读会话预览 | Ctrl+X 永久删除整个会话，`i` 查看元数据详情 |

Archived 是与 Idle、Working 同级的分组，初次默认收起。标题只显示 `Archived (数量)`，不带展开、收起符号；选中标题时提示当前可执行的 `Enter to expand` 或 `Enter to collapse`。静态状态组标题不进入键盘导航，Archived 标题可以选中；这是交互差异，不是父子层级。

预览关闭后恢复原列表当前项、分组展开状态、焦点和草稿。预览读取打开时的会话快照，上翻时加载较早历史，不订阅实时输出；再次打开读取最新内容。取消归档恢复主会话的可输入状态，不重新运行已结束的 Turn 或子 agent。

## 推广范围与待统一项

**Proposed：把上下文规则推广到所有交互面板，通过共享控件统一行为；不把每个面板都改成同一套单键。** 本节是待实现的统一方向；实际可用按键以“当前面板和焦点行为”为准。

| 范围 | 统一方向 | 必须保留的边界 |
| --- | --- | --- |
| 选择列表：Model、Theme、Config、Keymap、Session 等 | 列表焦点支持 `j` / `k` 与上下同义；具备搜索时用 `/` 明确进入搜索；Enter 执行当前主动作 | 搜索或编辑有焦点时，`j`、`k`、`/` 都是文字；没有搜索的列表不显示搜索提示 |
| 只读阅读：Status、详情、会话预览 | 统一方向键、分页、Home/End、`j` / `k`；明确滚动单位与历史加载边界 | 预览的历史分页属于会话能力，短详情不能因此获得会话操作 |
| 页签 | 统一 Tab/Shift+Tab 切换；页签焦点内左右切换 | 列表左右调整值、编辑光标左右移动时，不切页签 |
| 编辑与录制 | 进入时明确显示编辑对象或录制提示；退出恢复父列表 | 输入和录制优先；禁止列表单键或应用命令抢走字符 |
| 审批与提问 | 复用清晰的选择和焦点表达，保留明确提交动作 | 不给接受、拒绝、发送或删除盲目增加单字母键；Esc 不推断业务结果 |
| Queue 与 Agents | 统一焦点入口、返回输入框的规则和操作提示 | 保留排队发送与 Thread 切换的对象动作，不强行套用会话列表的 Space 预览 |

首先在 `ListSelection` 和阅读控件中统一同类动作，再让使用它们的面板获得一致行为。业务代码提供动作与可用条件，共享控件解释基础导航；应用层决定当前活动上下文和允许的应用命令。不为每个面板复制一份键表，也不按颜色、标题或高度判断模式。若以后允许用户配置这些按键，绑定必须带上下文范围，不能把面板内字母放进全局快捷键表。

退出规则以“一次返回一层”为目标：编辑或录制返回父列表，搜索返回列表并保留查询，列表关闭面板，详情或预览恢复打开前的位置。当前 `ListSelection` 的搜索 Esc 仍直接关闭面板，需要后续改动并验证，不能把目标行为当作现状。待处理审批与提问仍是明确例外；它们等待业务结果，不能通过退出姿态伪造结果。不额外引入全局 `q` 关闭，避免增加第二套退出规则。

自动重复也需要统一：导航与滚动允许 Repeat；打开、切换展开、恢复、删除、提交和关闭只处理 Press，Release 不产生动作。当前管理列表和预览已经区分导航与重复关闭；Status、详情和 Queue 仍只处理 Press，`ListSelection` 的普通列表导航与激活尚未完整区分事件种类。因此“所有面板长按都一致”尚未实现。

推广时先验证焦点边界：输入 `j/k/i/p/空格` 和粘贴不会修改背景草稿或触发列表动作，Esc 恢复正确父上下文；再验证动作重复、异步完成后目标变化、滚动与历史分页、鼠标与键盘的同一动作入口。可见提示、按键分发和测试必须一起更新。

## 交互状态

| 用户看到的状态 | 代表什么 | 视觉结果 | 是否改变键盘当前项 |
| --- | --- | --- | --- |
| 焦点 | 该区域正在接收键盘输入 | `ListSelection` 的搜索框只显示输入光标，列表保留键盘当前项，不增加额外紫色焦点层；其它组件沿用自己的焦点表达 | 否 |
| 可操作内容 | 命令展开、链接、路径或 `Open` 等内容具有动作 | 动作前景；链接同时使用下划线 | 否 |
| 键盘当前项 | Enter、Space 或左右键将作用于该项 | 选择前景/背景与粗体 | 是 |
| 已生效项 | 当前 Tab、模式或已经应用的值 | 强调色块，失焦后仍保留 | 否 |
| 鼠标悬停 | 指针当前位于可点击目标上 | `ListSelection` 中前景变为深色，不增加底色，不显示键盘当前标记；其它组件沿用自己的悬停色 | 否 |
| 鼠标按下 | 左键已经按下但尚未形成点击或拖动 | 独立按下前景/背景 | 否 |
| 禁用 | 目标可见但不可操作 | 禁用前景，不响应悬停或按下 | 否 |
| 文字框选 | 用户正在选择当前终端帧中的字符 | 独立文字选区前景/背景 | 否 |

可操作内容描述目标的能力，不表示焦点、选择或悬停。焦点、键盘当前项、已生效项、鼠标悬停和鼠标按下是可以同时存在的事实，不能先压缩成一个状态。鼠标移动不能覆盖键盘当前项；两者位于不同行时必须同时可见。颜色不能是唯一线索：焦点使用键盘当前标记、焦点边框或输入光标，键盘当前项使用粗体或反色，悬停在无颜色终端中使用下划线，已生效项使用反色或粗体。具有打开能力的链接还必须使用下划线并携带真实终端超链接目标。

`highlight` 只用于语法高亮、搜索命中等具体能力名称，不是 TUI 主题字段，也不表示某种通用交互状态。Transcript Markdown 尚未实现可点击链接；以后增加链接时使用 `actionForeground + UNDERLINED + OSC 8`，并把命中目标和打开动作交给对应组件与 Host。

终端窗口重新获得焦点时只触发一次后台剪贴板图片可用性检查，不转移 TUI 内部焦点，也不修改草稿。检测到图片时，顶部提示显示 `image in clipboard · ctrl+v to paste` 5 秒，重复获得焦点会重新计时，粘贴成功后立即清除；没有图片或检查失败时不显示错误。

每个可交互目标分别保存：所在区域是否有焦点、目标是否已生效或禁用、目标是否为键盘当前项、鼠标是否悬停、鼠标是否按下。功能状态中的成功、警告和失败不属于交互状态，不能代替焦点、选择或悬停。

绘制优先级固定为：禁用、鼠标按下、键盘当前、鼠标悬停、已生效、普通。焦点是独立覆盖层，只改变状态列、边框或输入光标；按下必须暂时覆盖当前项颜色以确认点击，松开后恢复当前项颜色。底层事实不因颜色优先级丢失，例如已生效项仍保留身份标记，键盘当前项仍保留自己的标记。

| 目标 | 普通 | 获得焦点 | 键盘当前 | 已生效 | 鼠标悬停 | 鼠标按下 |
| --- | --- | --- | --- | --- | --- | --- |
| 命令面板 | 普通顶边 | 顶边与粗体标题使用焦点色 | 不适用 | 不适用 | 不适用 | 不适用 |
| Tab | 普通文字 | 状态列显示键盘当前标记 | 不单独改变 Tab 身份 | 强调色块 | 悬停色并保留已生效粗体 | 按下色并保留已生效粗体 |
| SearchBox | 浅灰边框 | 保持浅灰边框并显示输入光标 | 不适用 | 不适用 | 深色边框，不增加底色 | 按下色边框 |
| `ListSelection` 列表项 | 浅灰文字 | 状态列属于所在区域 | 深色、粗体和键盘当前标记 | 由内容自身的勾选或状态文字表达 | 深色文字，不增加底色，不显示键盘当前标记 | 按下色 |
| 按钮或选择项 | 普通文字 | 所在区域显示焦点 | 选择色与键盘当前标记 | 已提交结果不继续伪装成交互项 | 悬停色 | 按下色 |
| Transcript 动作 | 输出和用户输入使用各自的固定标记 | Transcript 模式由状态栏表达 | 所在消息使用选择色 | 展开后以紧随其后的详情连接符表达，不改变输出标记 | 悬停色 | 按下色 |
| Agent Thread 行 | 普通文字 | 当前行使用选择色 | 选择色 | 已查看 Thread 使用强调色块和 `●` | 不适用 | 不适用 |

命令面板中的页签统一复用 `TabListState`：`Tab` 或右方向键切换到下一页，`Shift+Tab` 或左方向键切换到上一页，首尾循环。当内容区也使用左右键调整当前项时，只有页签区获得焦点后才用左右键切换；`Tab` 仍直接切换页签。

Status 面板复用统一的页签样式和交互，当前页签通过交互状态的强调样式表达，不在文字中添加方括号。Session 与 Processes 各自保留 PageUp/PageDown 和 Home/End 的滚动位置。操作提示行显示 `Tab to switch · Esc to close`，不枚举等价的方向键，滚动键继续可用，不重复占用提示行。

## 操作提示文案

`KeyHints` 与 HitBar 中的操作提示统一写成 `<按键> to <动作>`，按键名使用界面中的标准大小写，例如 `Esc`、`Enter`、`Space` 和 `Ctrl+X`。共享的 `KeyHints` 和 `ListSelection` 接口接收动作本身并统一补上 `to`，调用处不能自行拼接 `Esc close`、`Enter apply` 等文案。

`Esc` 的动作必须按退出后的结果命名：关闭当前临时界面并恢复原上下文用 `Esc to close`；放弃编辑、录制、自定义输入或等待中的组合键用 `Esc to cancel`；从列表选择或 Thread 切换焦点回到聊天输入区用 `Esc to return to input`。`Esc Esc` 表示连续按两次 Esc 的真实快捷键序列，不属于操作提示句式，不改写。

Queue 是 Session 页面里的消息区域，不是命令面板。ChatInput 在 Turn 运行时用 Enter 排队，用 Ctrl-Enter 单次 Steer；Alt-Up 把焦点交给 Queue 最新可编辑项。Queue 获得焦点后必须同时显示 `>` 当前项和 HitBar 键位，Up/Down 选择，Enter 恢复，Ctrl-Enter 立即发送，Ctrl-Up/Down 调序，Delete 删除，Esc 或从最后一项继续向下返回 ChatInput；鼠标单击一行只选中该行，不能改变键盘动作含义。

## 样式映射

本文只决定交互事实与绘制优先级。输入提示、键盘当前项、输出标记、颜色值、边线和无颜色终端中的文字属性统一由[样式契约](styles.md)定义；交互实现只能请求对应的语义角色，不能自行选择字符或颜色。

## 鼠标规则

鼠标捕获开启时，事件顺序固定如下：

1. 移动只更新悬停目标并请求重绘，不修改键盘焦点、键盘当前项或候选过滤结果。
2. 左键按下记录按下目标并开始区分点击与拖动；按下目标使用按下色。
3. 发生拖动后立即清除按下目标，进入文字框选；拖动过程中不触发页面动作。
4. 左键松开且没有拖动时，只激活松开位置命中的准确目标；是否转移焦点必须是该控件的明确动作，不能由悬停隐式决定。
5. 松开、Resize、页面切换或目标失效时清除按下状态；指针离开可交互目标时清除悬停状态。
6. Mouse interactions 关闭时，终端拥有鼠标，TUI 不保存悬停、按下或文字框选状态。
7. 指针位于正文区时，滚轮按五行滚动正文；Welcome 属于正文历史的起点，内容溢出后随正文滚走，滚回绝对顶部时重新出现。继续向上越过当前已加载内容的顶部时，使用稳定 Turn 游标请求上一页历史，即使当前内容不足一屏也不能无响应。离开最新位置后，当前顶部页眉行或正文单元与单元内行偏移保持不变，新消息和流式增量不能把正在阅读的内容顶走。点击正文区底部的 `Jump to bottom (click) ↓`、按 Ctrl-End 或提交新消息进入同一个回到最新动作。该控件不属于 `TopTip`。

点击和键盘提交必须进入同一个控件动作，不允许鼠标路径直接执行另一份业务副作用。悬停仅用于呈现；命中测试、键盘当前项和动作映射仍由各组件拥有。

## 所有权与实现约束

组件拥有焦点、当前项、已生效项、禁用和命中结果；应用层拥有当前页面的悬停与按下目标；统一渲染底座接收这些独立事实，并按[样式契约](styles.md)映射为 Ratatui `Style`；主题资源拥有颜色读取、校验和终端色阶转换。命令面板只提供产品内容和动作身份，不能直接使用 Ratatui 固定颜色，也不能把产品结果颜色当成交互颜色。

交互验收至少覆盖：键盘当前项与另一行悬停同时可见、按下与拖动分流、禁用项没有鼠标反馈、已生效 Tab 失焦后仍可识别，以及无颜色终端下不依赖颜色的状态区别。样式验收另外覆盖 Dark、Light、Colorblind 颜色映射、ANSI 色阶转换和固定字符角色。测试使用 Ratatui buffer 中的语义样式和状态断言，不使用截图作为通过依据。
