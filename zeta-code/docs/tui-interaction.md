# Zeta Code TUI 交互与颜色语义

> 状态：Current interaction contract。
> 本文拥有 Zeta Code TUI 的键盘、鼠标与交互颜色语义；[TUI 架构](tui.md)拥有整体状态、事件和渲染边界，[crate README](../tui/README.md)记录主题文件格式与实现入口。

## 快速理解

同一个交互状态在 editor、picker、Tab、搜索框、列表、补全、确认页和 Session Manager 中必须表达相同含义。组件保存焦点、当前项、已生效项和鼠标目标等事实，统一渲染底座把这些事实映射为颜色与终端样式；组件和功能页面不能自行挑选白、黑、红或紫色。

| 用户看到的状态 | 代表什么 | 视觉结果 | 是否改变键盘当前项 |
| --- | --- | --- | --- |
| 焦点 | 该区域正在接收键盘输入 | `ListSelection` 的搜索框只显示输入光标，列表保留键盘当前项，不增加额外紫色焦点层；其它组件沿用自己的焦点表达 | 否 |
| 可操作内容 | 命令展开、链接、路径或 `Open` 等内容具有动作 | 动作前景；链接同时使用下划线 | 否 |
| 键盘当前项 | Enter、Space 或左右键将作用于该项 | 选择前景/背景与粗体 | 是 |
| 已生效项 | 当前 Tab、模式或已经应用的值 | 强调色块，失焦后仍保留 | 否 |
| 鼠标悬停 | 指针当前位于可点击目标上 | `ListSelection` 中前景变为深色，不增加底色，不显示 `❯`；其它组件沿用自己的悬停色 | 否 |
| 鼠标按下 | 左键已经按下但尚未形成点击或拖动 | 独立按下前景/背景 | 否 |
| 禁用 | 目标可见但不可操作 | 禁用前景，不响应悬停或按下 | 否 |
| 文字框选 | 用户正在选择当前终端帧中的字符 | 独立文字选区前景/背景 | 否 |

可操作内容描述目标的能力，不表示焦点、选择或悬停。焦点、键盘当前项、已生效项、鼠标悬停和鼠标按下是可以同时存在的事实，不能先压缩成一个状态。鼠标移动不能覆盖键盘当前项；两者位于不同行时必须同时可见。颜色不能是唯一线索：焦点使用 `❯`、焦点边框或输入光标，键盘当前项使用粗体或反色，悬停在无颜色终端中使用下划线，已生效项使用反色或粗体。具有打开能力的链接还必须使用下划线并携带真实终端超链接目标。

`highlight` 只用于语法高亮、搜索命中等具体能力名称，不是 TUI 主题字段，也不表示某种通用交互状态。Transcript Markdown 尚未实现可点击链接；以后增加链接时使用 `actionForeground + UNDERLINED + OSC 8`，并把命中目标和打开动作交给对应组件与 Host。

## 交互状态

每个可交互目标分别保存：所在区域是否有焦点、目标是否已生效或禁用、目标是否为键盘当前项、鼠标是否悬停、鼠标是否按下。功能状态中的成功、警告和失败不属于交互状态，不能代替焦点、选择或悬停。

绘制优先级固定为：禁用、鼠标按下、键盘当前、鼠标悬停、已生效、普通。焦点是独立覆盖层，只改变状态列、边框或输入光标；按下必须暂时覆盖当前项颜色以确认点击，松开后恢复当前项颜色。底层事实不因颜色优先级丢失，例如已生效项仍保留身份标记，键盘当前项仍保留 `❯`。

| 目标 | 普通 | 获得焦点 | 键盘当前 | 已生效 | 鼠标悬停 | 鼠标按下 |
| --- | --- | --- | --- | --- | --- | --- |
| Editor / picker | 普通顶边 | 顶边使用焦点色 | 不适用 | 标题使用强调色块 | 不适用 | 不适用 |
| Tab | 普通文字 | 状态列显示 `❯` | 不单独改变 Tab 身份 | 强调色块 | 悬停色并保留已生效粗体 | 按下色并保留已生效粗体 |
| SearchBox | 浅灰边框 | 保持浅灰边框并显示输入光标 | 不适用 | 不适用 | 深色边框，不增加底色 | 按下色边框 |
| `ListSelection` 列表项 | 浅灰文字 | 状态列属于所在区域 | 深色、粗体和 `❯` | 由内容自身的勾选或状态文字表达 | 深色文字，不增加底色，不显示 `❯` | 按下色 |
| 按钮或选择项 | 普通文字 | 所在区域显示焦点 | 选择色与 `❯` | 已提交结果不继续伪装成交互项 | 悬停色 | 按下色 |
| Transcript 动作 | 动作前景 | Transcript 模式由状态栏表达 | 所在消息使用选择色 | 展开状态由 `▾/▸` 表达 | 悬停色 | 按下色 |
| Subagent 行 | 普通文字 | 当前行使用选择色 | 选择色 | 已查看 Thread 使用强调色块和 `●` | 不适用 | 不适用 |

## 内置交互颜色

交互颜色是主题的一部分。普通 dark/light 和色觉友好主题必须分别提供完整值，不能通过运行时混色或从其他产品主题读取。`accent` 表示品牌文字和运行状态，`actionForeground` 表示可操作能力，其他字段表示交互状态。

产品结果颜色与交互颜色分开：

| 主题字段 | Dark | Light | Dark Colorblind | Light Colorblind | 用途 |
| --- | --- | --- | --- | --- | --- |
| `success` | `#3FB950` | `#1A7F37` | `#58A6FF` | `#0969DA` | 已成功完成 |

Transcript 的用户消息使用独立表面颜色，不复用选择、悬停或 Overlay 状态：`userMessageBackground` 在 Dark 与 Dark Colorblind 中为 `#161B22`，在 Light 与 Light Colorblind 中为 `#F6F8FA`。

TrueColor 直接使用表中颜色；ANSI-256 和 ANSI-16 通过统一的终端色阶映射得到最近颜色。Monochrome 不依赖颜色：焦点为 `BOLD` 加 `❯`，已生效项为 `REVERSED + BOLD`，键盘当前项为 `REVERSED + BOLD`，悬停为 `UNDERLINED`，按下为 `REVERSED + BOLD`，禁用为 `DIM`，文字框选为 `REVERSED`。

## 鼠标规则

鼠标捕获开启时，事件顺序固定如下：

1. 移动只更新悬停目标并请求重绘，不修改键盘焦点、键盘当前项或候选过滤结果。
2. 左键按下记录按下目标并开始区分点击与拖动；按下目标使用按下色。
3. 发生拖动后立即清除按下目标，进入文字框选；拖动过程中不触发页面动作。
4. 左键松开且没有拖动时，只激活松开位置命中的准确目标；是否转移焦点必须是该控件的明确动作，不能由悬停隐式决定。
5. 松开、Resize、页面切换或目标失效时清除按下状态；指针离开可交互目标时清除悬停状态。
6. Mouse interactions 关闭时，终端拥有鼠标，TUI 不保存悬停、按下或文字框选状态。

点击和键盘提交必须进入同一个控件动作，不允许鼠标路径直接执行另一份业务副作用。悬停仅用于呈现；命中测试、键盘当前项和动作映射仍由各组件拥有。

## 所有权与实现约束

组件拥有焦点、当前项、已生效项、禁用和命中结果；应用层拥有当前页面的悬停与按下目标；统一渲染底座接收这些独立事实并映射为 Ratatui `Style`；主题资源拥有颜色读取、校验和终端色阶转换。功能页面只提供产品内容和动作身份，不能直接使用 Ratatui 固定颜色，也不能把产品结果颜色当成交互颜色。

交互验收至少覆盖：键盘当前项与另一行悬停同时可见、按下与拖动分流、禁用项没有鼠标反馈、已生效 Tab 失焦后仍可识别、Dark/Light/Colorblind 颜色映射、ANSI 色阶转换，以及 Monochrome 下不依赖颜色的状态区别。测试使用 Ratatui buffer 中的语义样式和状态断言，不使用截图作为通过依据。
