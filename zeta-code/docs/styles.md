# Zeta Code TUI 样式

> 状态：Current style contract。
> 本文拥有 Zeta Code TUI 的可见字符、边线、文字属性、颜色角色和终端色阶退化规则；[界面部位词典](LAYOUT.md)拥有区域名称与位置，[交互契约](tui-interaction.md)拥有键盘、鼠标和状态变化，[TUI crate README](../tui/README.md)记录主题文件格式与实现入口。

## 快速理解

输入提示、键盘当前项和输出必须使用不同字符，让用户在无颜色终端里也能直接分清“正在输入”“将要操作”和“系统输出”。提示符是固定文字，输入光标由终端单独绘制，两者不是同一个元素。

| 用户看到的内容 | 固定样式 | 含义 |
| --- | --- | --- |
| 输入框和历史用户消息 | `>` | 用户输入；输入框使用正常前景色，历史消息使用弱化前景色 |
| 键盘当前项 | `>` | Enter、Space 或方向键当前会作用于这一项 |
| Agent、思考和执行输出 | `●` | 系统输出；颜色表达普通、运行、成功或失败 |
| 展开详情 | `└─` | 下一行属于上一条输出 |

## 输入提示符和光标

输入框首行固定以 `> ` 开始，续行留出相同的两列宽度。提交后，历史用户消息和本地命令输入行继续使用 `>`，但改用弱化前景色。`>` 不参与光标移动，也不表示输入框是否聚焦。

输入光标由终端绘制在草稿的当前编辑位置。TUI 只设置光标位置和显隐，不把方块、竖线或下划线写进 Ratatui buffer，因此实际形状遵循用户的终端设置。即使颜色不可用，固定的 `>` 与可移动光标仍能区分提示符和编辑位置。

Vim Insert 模式使用同一个 `> `；Normal 和 Visual 模式继续使用各自的模式提示，避免把不可直接输入的状态伪装成普通输入框。

## 运行提示

计划中的独立 Agent 运行提示使用 `✻`，只表示当前 Turn 尚未结束、Agent 正在思考或处理。它不能代替输入提示符、输入光标、历史用户消息或已经结束的输出圆点。当前实现尚未绘制这条独立运行提示；实现时必须从权威 Turn 状态读取，不能从正文或计时猜测。

## 交互颜色

交互颜色是主题的一部分。普通深色、浅色和色觉友好主题分别提供完整值，不能通过运行时混色或从其他产品主题读取。`accent` 表示品牌文字和运行状态，`actionForeground` 表示可操作能力，其他字段表示交互状态。Auto 按终端背景亮度选取一套语义颜色，但基础前景和背景保持终端默认色；显式主题使用调色板中的固定基础前景和背景。

## 正文样式

正文输出圆点按语义使用主题字段，正文继续使用正常前景色，颜色不能扩散到整段内容：

| 输出 | 圆点颜色 | 无颜色时的线索 |
| --- | --- | --- |
| 普通回答、思考、读取和搜索 | `muted` | 消息正文或工具名称 |
| 命令已提交或正在运行 | `warning` | `Running` 文案，或尚未出现结果分支 |
| 命令成功 | `success` | `Ran` 文案和结果分支 |
| 文件写入、编辑或补丁成功 | `accent` | 工具名称和结果分支 |
| 工具失败、拒绝或系统错误 | `danger` | `failed`、错误或拒绝文案 |
| 提醒和等待确认 | `warning` | 提醒正文 |

可展开的输出在折叠和展开时都保持同一个实心圆；展开后由下一行的 `└─` 表达详情归属。鼠标悬停和按下只临时覆盖圆点所在的交互区域，键盘仍通过正文选择样式和底栏中的 `Space` 提示表达当前操作目标。

正文中的用户消息和本地命令输入行使用独立表面颜色，命令结果仍使用普通背景。该表面不复用选择、悬停或浮层状态：`userMessageBackground` 在 Dark 与 Dark Colorblind 中为 `#161B22`，在 Light 与 Light Colorblind 中为 `#F6F8FA`。

正文离开最新位置时，`Jump to bottom (click) ↓` 覆盖在正文区最后一行中央，普通状态使用 `transcriptJumpBackground` 灰色表面；悬停和按下分别切换到统一的 `hover*` 与 `pressed*` 交互颜色。文案中的 `(click)` 是固定可点击线索，不能由颜色替代。

## 输入框边线

输入框只显示一条顶边和一条底边，两条边都贯穿可用宽度并使用 `chatInputChrome`。提示符、草稿和光标位于两条边之间；边线不承担焦点含义，输入光标才表示输入位置。

## 终端色阶

TrueColor 直接使用主题颜色；ANSI-256 和 ANSI-16 通过统一的终端色阶映射取得最近颜色。Monochrome 不依赖颜色：焦点使用粗体以及对应的焦点标记或输入光标，已生效项和键盘当前项使用反色加粗，悬停使用下划线，按下使用反色加粗，禁用使用弱化，文字框选使用反色。
