# 行为规格

要求版本：2026-09-08，来源见 [intent.md](intent.md)。

- AC-1：打开官方或自定义表单只选中字段；上下键移动，不激活输入。Enter 进入编辑；文字和粘贴仅在编辑中生效。显示当前位置标记。
- AC-2：Enter 确认已有字段，保存成功后退出编辑并留在当前字段；无改动不发请求。失败保留输入以重试。Esc 撤销当前编辑，退出编辑后再 Esc 返回页签。
- AC-3：新建表单逐字段明确编辑、确认到草稿；确认不自动移至下一项。切换页签保留草稿，不自动保存；创建是独立动作。
- AC-4：Fetch 只使用已保存配置，显示加载；成功展示模型，空列表和失败明确报告并清除旧列表。可重试；过期请求不能覆盖新状态，刷新不写配置或凭据。
- AC-5：每个页签提供启用 bool，默认启用。禁用页签保留位置并显示禁用样式；Tab、Shift+Tab、左右键及直接选择均不能进入。替换页签使当前项禁用后选择下一个启用项；全部禁用时无活动页签且 Enter 不进入正文，恢复启用后可继续使用。
- AC-6：宽窄终端当前字段可见，Key 不出现在字符输出中；重复/释放键事件不重复提交或切页。

模型发现结果由后端提供结构化分类；TUI 负责显示文案。协议 revision 更新并同步生成产物；配置和秘密持久化归属不变。真实账号不属于本轮测试依赖；用脚本化模型服务验证发现结果。

## 要求补充 v2

- AC-7：可复用 `TextField` 自己解释 Enter/Esc、输入与粘贴、重复键、提交等待和按键提示。业务只接收 Submit，并用 accept/reject 报告结果；提交时退出编辑且不会重复提交，失败恢复编辑并保留内容。移出字段只暂停编辑并保留草稿，再选中时不会自行激活输入；Esc 恢复上次确认值。OpenAI 名称、地址和 Key 都接入该控件，不再分别解释这些键。
- 控件继续复用已有 SearchBox 的文本编辑与字符绘制；实时搜索保持其既有规则，不转换为需要保存的字段。掩码值不进入 Debug/字符输出，替换和销毁输入时清除旧缓冲内容。
