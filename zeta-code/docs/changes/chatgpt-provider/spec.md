# 行为要求

- AC-1：Providers 显示独立的 ChatGPT subscription，进入账户页面，不打开 API key 输入框。
- AC-2：读取账户后显示登录状态和方案；未登录或需重新登录时可启动现有设备码登录，页面显示验证地址与一次性代码。
- AC-3：登录等待期间可取消；完成通知更新状态，失败显示原因并可重试。返回 Providers 不终止登录，重新进入可继续查看和取消。
- AC-4：已登录可退出 Zeta 账户；退出后刷新状态。账户修改由共享后端负责，TUI 不接触 token。
- AC-5：所有操作可通过键盘完成，Esc 返回上一层；异步结果不得重开已经关闭的页面，也不能让旧账户摘要覆盖新状态。
- INV-1：TUI 不接触 token 或浏览器 Cookie；认证由后端按 Codex 兼容存储约定处理，不转换为 API key 计费。

后续认证扩展采用只读复用，现行要求及适用限制见[认证兼容规格](../../../../zeta-rs/docs/changes/chatgpt-auth/spec.md)。
