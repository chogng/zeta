# 行为要求 v1

- AC-1：有可见页签的当前面板，在页签、正文或搜索焦点下按 Tab / Shift+Tab，分别切到下一个 / 上一个启用页，首尾循环；不调整设置或移动字段。仅首次 Press 执行，Repeat / Release 不重复切页；单页保持原页，空列表仍能切页。
- AC-2：切页保留搜索词与当前焦点区域；列表选择收敛到新页首项。字段草稿及编辑状态保留，返回原页可继续编辑；切页不触发保存，已有请求仍归属原连接，旧结果不改变当前页。
- AC-3：字段与 Issue 底部动作通过方向键可达，页签左右键只在页签焦点下切页；正文左右仍调整值，输入左右仍编辑文本。
- AC-4：独立详情、PR、正在创建任务、快捷键录制和输入补全保留各自输入，不切背景页；没有可见页签的内嵌列表不消费隐藏页签切换，不再用 Tab 调整设置。
- AC-5：提示、帮助和长期规格与规则一致；真实 Windows PTY 验证正文与搜索切页、反向切页、表单草稿返回及窄窗口。

失败、空结果和加载中允许切换 Issue 查询，按请求代次拒绝旧结果。任务创建期间保留独占输入以等待明确结果。无新增网络接口、凭据或重启恢复契约。
