# Tab 切页一致性

解决 [issue #17](https://github.com/chogng/zeta/issues/17)：有页签的当前面板中，Tab 不随正文焦点变成移动字段或调整设置。用户于 2026-09-08 接受评估方案。

范围为 zeta-code TUI；聊天补全、独立弹窗和快捷键录制保留输入归属。无持久化格式或共享后端变化。
