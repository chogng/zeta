# PR #20：浮层隔离与跨 Thread 本地正文

修复评审指出的两处数据与交互问题：浮层外的鼠标事件不再穿透正文，切换 Thread 不再删除本地命令。长期要求见[终端规格](../spec/terminal.md)，实现职责见 [TUI 设计](../design/tui.md)。

## 验收范围

| 要求 | 实现与回归 |
| --- | --- |
| AC-1 浮层隔离 | 详情与补全浮层外的滚轮、按下、拖动、松开全部消费；跨边界拖动取消；关闭后正文恢复滚动 |
| AC-2 浮层内部可用 | 详情内部滚轮仍改变详情字符输出，补全点击沿用已有事件路径 |
| AC-3 Thread 本地记录 | 真实 App 提交 `/status` 后切换 35 个 Thread，返回并重复接收快照，检查本地内容及单元身份不变；其他 Thread 记录不混入 |
| AC-4 分页与清空 | 最近一页未包含本地命令前面的消息时保留该记录；加载旧页后恢复顺序与身份，重复分页不复制；显式清空阻止记录复活 |
