# 界面语言设置：意图

来源与接受依据：用户要求精简 Config 页摘要，并增加日语、英语、中文、法语切换。状态／版本：v1，实现中。

## 问题与目标

Config 页重复展示模型、审批模型和供应商数量，但这些信息已有独立入口，挤占了设置列表。用户希望移除这三行，并在同一页面选择 TUI 界面语言；语言读取需要经过一个统一接口，避免各页面自行判断。

## 范围

- 包含：移除三条只读摘要；增加英语、日语、中文、法语的有界语言设置；保存到当前 TUI profile；保存成功后立即刷新 Config 根页面文字。
- 约束：Providers 和 Language servers 页签及其能力保留；语言设置不改变后端返回内容、模型回复或代码内容；无效持久化值必须拒绝，不能静默改成默认值。
- 当前依据：TUI 设置由 `config` 解释并保存到 `[tui]`，App 只通过完成事件更新可见状态；跨页面语言与文案身份由 TUI 根级接口维护。
- 工作类型：B 类新功能。
