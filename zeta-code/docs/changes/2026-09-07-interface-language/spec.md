# 界面语言设置：规格

意图：[intent.md](intent.md) v1。状态／版本：v1，实现中。

## 验收要求

| 编号 | 前提与动作 | 预期结果 | 验证方法 |
| --- | --- | --- | --- |
| AC-1 | 打开 `/config` 的 Config 页 | 不再显示 Preferred model、Approval review model、Providers 三条只读摘要；Providers 页签仍可进入 | 列表状态测试 |
| AC-2 | 查看并通过 Enter、Space、左、右切换 Language | 仅在 English、日本語、中文、Français 之间循环，当前值始终以文字显示 | 配置编辑器与 App 状态测试 |
| AC-3 | 保存语言并重新读取配置 | 当前 profile 的 `[tui].language` 使用 `en`、`ja`、`zh-CN` 或 `fr`；其他 `[tui]` 字段保持不变 | 设置单元测试与 App Server 集成测试 |
| AC-4 | 保存成功或启动时读取已选语言 | Config 根页面通过同一类型化文案接口显示对应语言；无效语言值产生可见配置错误并保留旧状态 | 文案、解码和完成事件测试 |

## 设计

- `config` 拥有持久化解码和保存；TUI 根级 `nls` 拥有 `Language`、`Message` 和类型化文案映射。语言是 TUI profile 级持久设置，不进入共享后端领域字段。
- 类型化文案键是 Config 根页面获取可见文字的唯一入口；组件显式接收语言，不使用进程全局可变状态。
- 后端提供的供应商名、语言服务器标识、模型内容和用户内容保持原文。
- INV-1：编辑任一已知 TUI 设置时，完整候选通过类型化解码，并保留未知兄弟字段。
- INV-2：语言选择不依赖颜色；当前值以可读文字显示，鼠标与键盘进入同一动作路径。
