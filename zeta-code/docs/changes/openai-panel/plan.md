# 实现计划

1. 已实现：共享 provider 配置保存稳定身份、显示名和 API 协议；运行时、凭据与模型目录读取同一连接定义（AC-4、AC-8、INV-1、INV-2）。
2. 已实现：按连接主动获取模型目录，结果进入模型选择；配置变化隔离旧目录，获取失败可重试（AC-5、INV-3）。
3. 已实现：通用 TabList 与输入控件替换 OpenAI 列表页，保留 ChatGPT 登录；支持草稿、创建及 Enter 确认后自动进入下一字段（AC-1～AC-4、AC-6～AC-8）。
4. 已执行定向行为测试、宽窄字符快照、配置重启及协议测试；构建与完整结果见验收。Unix PTY 场景入口已更新，本 Windows 环境未运行这些场景；真实账号验证尚未执行。
5. 已将页签焦点按键收回通用 `TabList`；表单和嵌入列表报告焦点边界，OpenAI 面板只协调页签、正文与业务动作（AC-7）。

有效交互约定已合入[长期规格](../../spec/providers.md)。[验收记录](verification.md)区分已验证行为与真实终端、账号的未验证范围。
