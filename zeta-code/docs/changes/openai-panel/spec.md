# 行为要求

本次要求取代旧的列表式面板规格；旧验收不覆盖本次改造。

| 编号 | 操作与结果 |
| --- | --- |
| AC-1 | 从 Providers 进入 OpenAI，使用通用 TabList。顺序为官方 API Key、ChatGPT 订阅、已创建的自定义 provider、New custom provider；创建后选中新 tab，新建入口始终在最后。 |
| AC-2 | 官方表单显示灰色只读的 `https://api.openai.com/v1` 和密码形式的 API Key 输入框。自定义表单依次显示 Provider name、Base URL、API Key、API protocol，每项均为标题在上、控件在下。协议可选 Responses 和 Chat Completions，新建默认 Responses，现有连接保留原协议。 |
| AC-3 | Enter 确认字段；成功后焦点自动移到下一字段并进入编辑，最后一项确认后聚焦底部操作按钮但不触发。上下键在非编辑状态移动字段。Esc 撤销本次字段编辑；移出字段、切换 tab 或关闭面板不保存。未改动不请求；非法值或保存失败保留输入及编辑焦点，显示原因供重试。保存不是网络认证验证。 |
| AC-4 | 新建字段按 Enter 确认到草稿，切换 tab 保留草稿，确认创建按钮才生成正式连接。名字与合法 Base URL 必填；API Key 可空。名字修改只改变显示名，内部身份稳定，各连接配置与 secret store 凭据隔离。 |
| AC-5 | 官方与自定义 API 表单底部提供获取模型列表。用户主动触发后使用已确认配置请求该连接的 `/models`，不提交其他字段尚未确认的输入；显示加载、结果、空目录或失败。失败可重试，保留连接。地址、协议或凭据变化后旧目录失效；目录项可用于 `/model` 选择，获取成功不证明模型可调用。 |
| AC-6 | ChatGPT tab 使用现有 Sign in、账号状态、取消和退出操作。切换 tab 或退出后，异步结果只更新对应状态，不能重新打开页面。 |
| AC-7 | Tab/Shift+Tab 遍历表单；非编辑状态下首字段向上进入 tab 栏，末操作向下停止。tab 栏由通用 TabList 解释 Tab/Shift+Tab 与左右切换，Enter/向下进入正文，Alt+左右键直接切换 tab。焦点明显，只读地址不进入编辑顺序；嵌入正文没有不可见页签焦点。窄终端保持当前字段可见。遵循固定面板的键盘交互约定，不开启鼠标捕获；输入不能激活背后内容。 |
| AC-8 | 配置持久化到共享配置 owner，Key 只进入 secret store，草稿由 TUI 持有。保存携带读取时 revision，冲突不得覆盖外部修改；旧请求不能覆盖新输入。重启恢复命名连接、协议和凭据状态。 |

INV-1：不同连接不共享 Key；明文 Key 不进入日志、普通配置或字符快照。

INV-2：请求严格使用用户选定的协议，不自动改用另一种协议。

INV-3：未完整创建的草稿不进入 provider 列表；目录失败不能撤销已保存配置。
