# OpenAI 配置面板

用户希望在 OpenAI 面板中用 tab 管理官方 API Key、ChatGPT 订阅和多个命名的自定义 provider。字段使用一行标题、下一行输入框，按 Enter 确认保存后自动移到下一字段并进入编辑，新建入口始终保留在最后。

本轮范围包括可选择的 API 协议（新建默认 Responses，可选 Chat Completions）、独立凭据、远程获取模型列表及重启恢复。用户已授权增加协议选择项；不自动探测或在失败时切换协议。保存配置、获取目录和模型调用成功分别表示不同结果。

2026-09-08 用户复测发现表单无法向上回到页签，并指出同类问题再次出现。本轮继续收敛原 AC-7：共享页签控件解释页签焦点按键，嵌入正文只报告焦点边界，OpenAI 面板只协调区域切换和业务动作。
