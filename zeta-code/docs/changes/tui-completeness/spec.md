# TUI 功能完整性：功能要求

用户应能从开始任务走到取得结果，并在失败、取消或切换后继续操作。以下按这个过程描述要求；AC 是验收编号，供[计划](plan.md)和[验收](verification.md)逐项引用。

依据：[目标 v1](intent.md)及已有交互、布局和架构约定。版本：v1，2026-09-07。这是现有产品的要求基线，条目是否实现、是否测试通过分别记录在验收文件中。

## 进入工作与继续会话

- **AC-1 · 首次进入。** 在选定目录启动 TUI，能够看清当前目录和连接，找到输入位置并开始任务。没有历史时显示可用的空界面；初始化或连接失败时说明原因，不留下半初始化的终端。
- **AC-2 · 继续已有工作。** 恢复指定会话及其中的对话后，看到原来的历史和任务状态，并能继续输入。指定对象不可恢复时显示错误，不能悄悄新建一个会话冒充恢复成功。

## 输入消息和上下文

- **AC-3 · 编辑与粘贴。** 输入中文、多行文字和长文本后，可以继续编辑、删除和提交。长粘贴占位符提交时还原原文；取消补全不清空草稿，空白输入不创建任务。
- **AC-4 · 添加图片。** 从本地路径或剪贴板加入图片，文字与图片顺序保持不变。删除图片时同时移除附件；读取、大小校验或上传失败时显示原因，不把失败附件当作已经发送。
- **AC-5 · 运行中继续输入。** 空闲时 Enter 开始任务；运行中 Enter 将内容排队，Ctrl+Enter 补充当前任务。补全打开时先确认候选；不能向当前任务切换 Skill 时，保留草稿并说明应排队或下一轮发送。
- **AC-6 · 修改排队消息。** 选中队列项后可以恢复编辑、调整顺序、删除或立即发送。恢复不能覆盖非空草稿，编辑后不能重复追加；发送失败不能丢掉队列内容。

## 看清执行并作出回应

- **AC-7 · 分清任务状态。** 能区分正在执行、等待用户、取消中、完成和失败。失败说明原因，已结束的任务不继续显示为运行中；一次错误不在多个区域重复刷屏。
- **AC-8 · 中断任务。** 在允许应用快捷键的上下文按 Ctrl+C，可以中断当前任务；取消中重复按键不重复提交。普通查询、设置保存或高频输出不能长时间阻塞中断。
- **AC-9 · 批准或拒绝。** 批准面板说明待处理操作，用户明确选择批准或拒绝后才提交。Esc 不替用户作决定；提交期间不能重复提交，失败可继续处理，超时显示明确结果。
- **AC-10 · 回答问题。** 用户可以选择答案或填写自定义回答。取消自定义编辑回到原问题，粘贴只进入答案编辑框；多问题按顺序处理，完整回答只提交一次。

## 找到、预览和切换会话

- **AC-11 · 浏览列表。** 打开会话管理器后能按状态找到会话。每个分组可独立展开收起；归档组默认收起，其他组默认展开，导航跳过收起的内容，刷新保留展开状态。
- **AC-12 · 只读预览。** 预览中可阅读、滚动和加载更早历史，但不能修改会话或背景草稿。关闭后回到原列表位置，保留焦点、分组状态和草稿；关闭后到达的旧结果不重新打开预览。
- **AC-13 · 切换与详情。** 打开会话或切换其中的对话后，输入、正文和后端订阅对应同一个对象，旧请求不能覆盖新界面。详情打开时刷新，关闭后停止；刷新不重置阅读位置。
- **AC-14 · 归档、恢复与删除。** 归档后能在归档组找到会话；恢复后可以继续使用，不重新执行已结束任务。永久删除只作用于明确选中的归档会话，失败时显示原因。
- **AC-15 · 分支与回退。** 从原对话创建分支或选择回退点后，进入正确的新对话；原对话不被改写。回退只继承目标之前应保留的历史，不能把回退当成重新执行历史任务。

详细导航和默认键位见[会话管理动作](../../spec/interaction.md#session-管理列表的动作)。

## 阅读和带走结果

- **AC-16 · 阅读长输出。** 普通文字、代码块和执行结果在宽窄窗口中可读。可展开的输出能查看详情；用户上翻后，新输出不强制跳到底部，返回最新位置的操作明确。内容被截断时保留省略说明。
- **AC-17 · 保留终端历史。** 已定稿正文按顺序进入终端历史；重绘、缩放、主题切换和恢复不会重复输出。输入框、补全和面板不混进对话历史，终端已有内容得到保留。
- **AC-18 · 复制和导出。** 可以复制最后回复，或将当前已加载正文导出到本机工作目录。已有文件不得覆盖，越界路径被拒绝；失败显示原因，任务状态不受影响。

这些要求不预先裁定完整 Markdown 或可点击链接的支持程度，见 Q-1。

## 设置和扩展能力

- **AC-19 · 修改设置。** 从设置、模型、主题或快捷键入口选择并保存后，当前界面与重新读取的值一致。无效输入、版本冲突或保存失败时给出原因，不覆盖其他设置，也不冒充保存成功。
- **AC-20 · 面板操作。** 列表、搜索、页签、编辑和快捷键录制各自接收正确输入；关闭或取消回到应有位置。输入字符不触发背景动作，提示与实际按键一致。
- **AC-21 · 使用 Skill 和补全。** 命令、文件、Plugin 和 Skill 候选可找到并插入当前输入，保留已有参数及附件。Skill 启用状态与提交的身份一致；旧查询结果不覆盖新输入，失效或不可用项不冒充可执行。
- **AC-22 · 管理 Connector 与 MCP。** 可以查看连接或启用状态，并执行当前支持的操作。设备码授权、断开和 MCP 启用失败时显示原因；需要在桌面完成的连接方式明确说明，不能显示成功假象。
- **AC-23 · 管理目录权限。** 添加目录、改变权限和撤销分别表达清楚。权限只作用于对应会话，操作经过后端校验；冲突或拒绝不改变界面中的已生效结果。

## 断线、退出和终端环境

- **AC-24 · 断线后恢复。** 传输断线后保留会话身份，由 CLI 尝试重连并重新读取历史。重连失败提供继续原会话的方法；旧连接待执行请求不自动重放。服务端正常关闭或协议错误不能无限重试。
- **AC-25 · 退出与挂起。** 正常退出、系统终止、启动到一半失败和 Unix 挂起恢复后，终端输入模式、鼠标捕获和光标恢复正确，不遗留后台任务。
- **AC-26 · 键盘、鼠标与窄窗口。** 核心流程可用键盘完成；窗口变窄后关键输入和返回操作仍可用，无颜色时能辨认当前操作目标。增强鼠标仅作用于可见的覆盖浮层；占布局高度的面板不响应 TUI 鼠标，浮层关闭后由终端处理历史滚动、选择和复制。
- **AC-27 · 查看资源。** 状态页能区分当前对话信息与本机进程信息。远程资源不算进本机合计；读数不可用时明确标注。没有可见需求时停止采样，读取失败不影响对话。

## 尚需确定的完成边界

以下问题会影响最终完成判断，暂不算已通过，也不默认排除。

| 编号 | 要决定什么 | 当前已知情况 |
| --- | --- | --- |
| Q-1 | 正文是否必须支持可点击链接、表格和更完整的 Markdown？ | 现有文档记录普通折行及代码块高亮，正文链接尚不可点击 |
| Q-2 | 本轮必须通过哪些操作系统、终端及复用器组合？ | 既有协议回放结果不足以证明所有真实终端；现有 CLI PTY 场景限定 Unix |
| Q-3 | 断线或重启后，未发送草稿、图片和本地队列是否必须恢复？ | 目前恢复身份只包含会话和对话；不能据此保证恢复未发送内容 |
| Q-4 | Welcome 宠物点击播放是否属于本轮交付？ | 已有规格和动作资源，Welcome 运行时仍只绘制静止帧 |

[正文绘制重构](../../spec/transcript-rendering.md)是实现方案，[内存诊断](../../spec/memory-diagnostics.md)由共享 Rust 后端负责。正文重构已有新实现，需按其规格验收；内存诊断已接入，独立验收见其规格链接。二者的状态与本轮用户流程验收分别记录。

本规格不引入架构变化。实施发现必须改变责任、接口或持久化时，先更新受影响要求及[架构设计](../../design/tui.md)，再调整计划。
