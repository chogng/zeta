# 行为要求

- AC-1：`/add-dir` 打开目录面板，`/` 或向上导航进入路径框；输入不筛掉已有目录，Enter 提交路径，显示 Adding directory…，等待时禁止重复提交。
- AC-2：服务端确认后，列表立即刷新；清空输入，显示规范路径，定位该目录的 Read files 权限项并移出输入焦点，面板保持打开。
- AC-3：已存在的路径不重复添加，提示 Directory already added 并定位已有目录；保留原权限。
- AC-4：空路径不提交，多行粘贴报错；服务端失败时显示原因，保留原文与输入焦点，可修改重试。路径中的连续空格保持原样。
- AC-5：等待时 Esc 关闭面板；关闭、重新打开或切换会话后，旧请求结果不影响新面板。
- AC-6：原有行内 `/add-dir 路径`、移除与权限修改继续可用。相对路径由服务端解析，添加结果返回规范路径供界面定位。

适用 Windows、Unix 的 TUI 键盘输入与粘贴；Web/Electron 不属于本次改动。状态、提交请求、字符输出分别验收。
