# 对话输入与任务交互

- 本文维护消息、附件、Queue、任务中断、审批、提问及输入补全。
- 会话管理见[sessions.md](sessions.md)，输出结构见[正文输出](transcript.md)，共用键位见[交互规则](interaction.md)。

## 输入与提交

| 场景 | 要求 |
| --- | --- |
| 中文、多行和长文本 | 可以编辑、删除和提交；长粘贴占位符提交时还原原文 |
| 空白输入 | 不创建任务；取消补全不清空草稿 |
| 图片路径与剪贴板 | 保持文字和图片顺序；删除图片同步移除附件；读取、大小校验或上传失败显示原因，不冒充已发送 |
| 运行中提交 | Enter 排队，Ctrl+Enter 单次 Steer；补全打开时先确认候选 |
| Steer 与 Skill | 当前任务不能切换 Skill 时保留草稿，说明应排队或下一轮发送 |
| Queue 恢复与发送 | 恢复不能覆盖非空草稿；编辑不重复追加，发送失败保留队列内容 |
| 任务状态 | 区分执行、等待用户、取消中、完成和失败；失败说明原因；结束后不继续显示运行，一次错误不在多处重复刷屏 |
| 中断 | 允许应用快捷键的上下文中 Ctrl+C 中断；取消中不重复提交；普通查询、设置保存和高频输出不能长时间阻塞中断 |

## 页面、辅助区域与浮层

| 界面 / 进入方式 | 完整操作方案 | 返回方式与必要区别 |
| --- | --- | --- |
| Session / 管理页面的输入框 | 字符编辑草稿；Enter 提交，运行中 Enter 排队、Ctrl+Enter 单次 Steer；Shift+Tab 切权限模式；Ctrl+V 粘贴图片；空输入时左右切页面，管理页 ↑ 进入管理列表，Session 页 ↓ 进入 Agents，Alt+↑ 进入 Queue | 编辑模式与候选状态由输入组件负责；普通字母不作为列表导航 |
| 正文条目选择 / 空输入时 Ctrl+↑或Ctrl+↓ | 列表导航；Space 展开可展开内容，Enter 查看完整详情；Ctrl+↑/↓ 保留已有条目选择入口 | Esc 回输入框；Space 展开输出，不承担会话预览 |
| Queue / Alt+↑ | 列表导航；Enter 恢复编辑，Ctrl+Enter 立即发送，Ctrl+↑/↓ 调序，Delete 删除 | Esc 回输入框；到边界保持焦点；Ctrl+C 保留中断当前运行的应用动作 |
| Agents / 空输入时 ↓ | 列表导航；Enter 切换所选 Thread | Esc 回输入框；到边界保持焦点，不向草稿输入字母 |
| 审批面板 | 选择导航；Enter 提交所选同意或拒绝；提交中不再响应提交 | Esc 不关闭、不自动拒绝；没有 Space 或单字母同意动作 |
| 提问面板 | 选择导航；Enter 回答当前问题或进入自定义输入；自定义输入接收文字与粘贴，Enter 确认 | 选项状态下 Esc 保持问题；自定义输入中 Esc 取消编辑，回到当前问题 |
| 详情浮层 / 会话 `i` 或正文 Enter | 阅读导航；其他按键不操作背景 | Esc 关闭当前详情并恢复原上下文 |
| 输入补全浮层 / `/`、`@`、`$` | 文字继续编辑查询；方向键选择，Enter/Tab 由候选类型确认；Esc 关闭候选 | 与输入框共同处理编辑；`j/k/空格` 不能当作通用阅读或选择命令 |
| Goal、Plan、TopTip、StatusLine | 展示信息，没有独立键盘焦点或快捷键 | 不为纯展示区域制造单键模式 |

- 输入框本身的字符编辑和 Vim 模式由现有编辑器负责，不能用面板键表重新定义。
- 应用默认键包括 Ctrl+C 中断或退出、空输入 Ctrl+D 中断或退出、Ctrl+O 复制最后回复、Ctrl+Z 挂起；空输入连续 Esc Esc 打开 Rewind。
- 这些仅在路由到应用上下文时可用，不能越过独占的面板、预览或请求处理器。
- 用户配置可以改变应用键位；本节列出的面板基础键当前固定，不通过应用快捷键表重绑。

## Queue 焦点

- Queue 是 Session 页面里的消息区域，不是命令面板。
- ChatInput 在 Turn 运行时用 Enter 排队，用 Ctrl-Enter 单次 Steer；Alt-Up 把焦点交给 Queue 最新可编辑项。
- Queue 获得焦点后必须同时显示 `>` 当前项和 HitBar 键位，Up/Down 选择，Enter 恢复，Ctrl-Enter 立即发送，Ctrl-Up/Down 调序，Delete 删除，Esc 返回 ChatInput；最后一项继续向下保持 Queue 焦点；鼠标不选择 Queue 条目，选择与编辑由键盘完成。

## 审批与提问的提交结果

| 场景 | 要求 |
| --- | --- |
| 审批 | 说明待处理操作；用户明确批准或拒绝后才提交；失败可继续处理，超时显示明确结果 |
| 多问题 | 按顺序收集选择或自定义回答，完整回答只提交一次 |
| 自定义回答 | 粘贴只进入答案编辑框；取消编辑返回原问题 |
| 提交中 | 禁止重复提交；Esc 不隐式批准、拒绝或回答 |

## 剪贴板提示

- 终端窗口重新获得焦点时只触发一次后台剪贴板图片可用性检查，不转移 TUI 内部焦点，也不修改草稿。
- 检测到图片时，顶部提示显示 `image in clipboard · ctrl+v to paste` 5 秒，重复获得焦点会重新计时，粘贴成功后立即清除；没有图片或检查失败时不显示错误。
