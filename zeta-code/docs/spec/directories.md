# 目录与权限

- 入口：`/add-dir` 打开目录面板；`/add-dir 路径` 支持行内添加。
- 目录和权限由 Session 持有，路径解析和校验由后端完成；新增目录默认没有权限。
- 通用导航见[交互规则](interaction.md)，共享权限语义见[环境访问](../../../docs/environment-access.md)。

## 添加目录

| 阶段 | 用户操作或条件 | 界面结果 |
| --- | --- | --- |
| 输入 | `/` 或向上导航进入路径框 | 输入不筛掉已有目录，路径中的连续空格保持原样 |
| 校验 | 空路径或多行粘贴 | 空路径不提交；多行粘贴显示错误 |
| 提交 | 路径框按 Enter | 显示 `Adding directory…`，禁止重复提交 |
| 成功 | 服务端确认 | 列表立即刷新，显示规范路径，清空输入；焦点移到该目录的 `Read files` 权限项，面板保持打开 |
| 重复 | 路径已存在 | 显示 `Directory already added`，定位已有目录，保留原权限 |
| 失败 | 服务端返回错误 | 在输入框下显示原因，保留原文及输入焦点，可修改重试 |

## 权限与返回

| 操作或事件 | 要求 |
| --- | --- |
| 列表 Enter | 执行当前项的移除目录或权限修改动作；添加本身不授予读取或写入权限 |
| 权限修改或撤销 | 仅作用于对应会话，经过后端校验；冲突或拒绝不改变界面已生效结果 |
| 输入框 Esc | 未等待时返回列表；等待添加时关闭面板 |
| 列表 Esc | 关闭面板并恢复输入 |
| 关闭、重新打开、切换会话 | 旧添加结果不能影响新面板 |
| 行内添加 | 使用同一后端路径解析与返回结果；原有移除及权限修改继续可用 |
