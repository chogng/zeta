# 会话管理、预览与恢复

- 本文维护会话列表、预览、详情、切换、归档、恢复与回退行为。
- 页面空间和分组排列见[管理页面布局](layout.md#session-管理页面)；请求与订阅由[TUI 架构](../design/tui.md#会话切换预览与详情)说明。

## Session 管理列表的动作

| 当前项 | Enter | Space | 其他动作 |
| --- | --- | --- | --- |
| 普通会话 | 打开会话 | 打开只读会话预览 | Ctrl+X 归档，`i` 查看元数据详情，`p` 置顶或取消置顶 |
| 所有分组标题 | 切换展开与收起 | 切换展开与收起 | 左收起、右展开；键盘 Enter/Space 与左右展开动作一致 |
| 归档会话 | 取消归档，保留管理页面 | 打开只读会话预览 | Ctrl+X 永久删除整个会话，`i` 查看元数据详情 |

- Idle、Working、Failed、Pinned 和 Archived 等分组标题都进入键盘导航，使用键盘展开或收起各自的会话列表。
- Archived 初次默认收起，其余分组默认展开；标题只显示分组名称和完整会话数量，不显示展开或收起符号；键盘当前项使用统一的 `>` 标记。
- 选中标题时提示 `Enter to expand` 或 `Enter to collapse`，折叠后当前项停留在标题，导航跳过隐藏的会话；会话列表刷新保留各组的展开状态。

预览关闭后恢复原列表当前项、分组展开状态、焦点和草稿。预览读取打开时的会话快照，上翻时加载较早历史，不订阅实时输出；再次打开读取最新内容。取消归档恢复主会话的可输入状态，不重新运行已结束的 Turn 或子 agent。

## 导航与阅读

| 区域 | 操作 | 返回与隔离 |
| --- | --- | --- |
| 管理列表 | 输入框按 ↑ 进入；↑↓ / k/j、Home/End、PageUp/PageDown 导航；每次翻页 12 项 | Esc 回输入框；没有 `/` 搜索；普通字符不写入背景草稿 |
| 会话预览 | ↑↓ / k/j 每次一行；PageUp/PageDown 按视口翻页；Home/End 到已加载首尾，顶部可加载更早历史 | 禁止输入、粘贴和会话修改；Esc 回原列表；关闭后的旧结果不重开预览 |
| 会话详情 | `i` 打开；方向键、k/j、翻页、Home/End 阅读 | Esc 恢复进入位置；其余按键不操作背景 |
| `/resume` | 搜索并 Enter 恢复选定会话，也支持行内参数 | 恢复对象不可用时显示错误，不新建会话冒充恢复成功 |

## 切换与生命周期

| 场景 | 要求 |
| --- | --- |
| 打开会话或切换 Thread | 身份、输入、正文、订阅同时对应目标对象；旧请求不能覆盖新界面 |
| 打开详情 | 展示根对话、分支、委派关系、状态、等待原因和结果；打开期间刷新，保留阅读位置 |
| 关闭详情或删除目标 | 停止读取；删除后关闭详情；晚到结果不得重开 |
| 归档、恢复、永久删除失败 | 显示原因，不能把未成功的操作显示为完成；永久删除仅作用于选中的归档会话 |
| 分支与回退 | 进入正确的新对话，原对话不被改写；回退只继承目标之前应保留的历史，不重跑历史任务 |
| 断线后继续 | 持久化身份和重新连接规则见[终端与连接恢复](terminal.md#连接恢复) |
