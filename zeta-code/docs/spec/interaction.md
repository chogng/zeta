# TUI 交互规格

本文规定输入、导航、确认和返回行为。下列键表使用默认键位；用户可修改的范围见[快捷键声明与保存](#快捷键声明与保存)。

按键由当前操作上下文解释。先看焦点在输入框、列表还是阅读区，再判断按键做什么；不能因为界面叫“面板”就给它统一的字母命令。布局上的浮层和输入上的独占是两个独立概念。

| 当前正在做什么 | 字母如何处理 | 退出原则 |
| --- | --- | --- |
| 写消息、搜索、编辑设置 | 输入文字 | 结束当前编辑；不同时操作背景列表 |
| 选择会话或列表条目 | 执行该列表明确提供的动作，其余字符不写进草稿 | 回到进入前的界面或输入区域 |
| 阅读预览或详情 | 滚动与阅读动作，不编辑内容 | 关闭当前阅读界面并恢复返回位置 |
| 录制快捷键 | 字母和组合键都是待录制数据 | 取消录制并返回设置列表 |
| 回答提问或审批 | 明确选择并提交 | 待处理请求必须有明确结果；Esc 不代替回答或拒绝 |

统一的是输入归属、焦点表达和返回规则；具体动作仍取决于对象。Enter 在普通会话上打开，在归档会话上恢复；Space 在会话列表上预览，在多选列表上可以切换选择。操作提示必须与当前动作一致。

## 按键上下文

上下文由页面、活动组件和组件内部焦点共同决定。命令面板可以在页签、搜索框、列表和编辑框之间切换；从列表进入搜索时，字符解释立即变成文字输入。无需额外建立一个跨页面的 Normal / Insert 模式；输入框自身已有的编辑模式仍由输入框负责。

“独占输入”表示当前交互先解释事件，并阻止无效按键误触背景。它不要求铺满终端，也不要求覆盖背景。详情浮层、Session 预览和命令面板都可以独占按键；输入补全则属于输入组件的编辑上下文，候选导航不能把普通文字变成命令。

当前应用先处理详情浮层、会话预览和已聚焦的管理列表，再处理待回答请求、命令面板与 Queue；其后才经过适用的应用快捷键、页面导航和输入组件。具体可用快捷键以各上下文的处理器为准，不能声称应用快捷键在任意面板内都能穿透执行。实现入口是 [`App::handle_key_at_in_area`](../../tui/src/app/state.rs)。

### 当前面板和焦点行为

下表记录当前实现。普通字母动作只对表中明确支持它的上下文生效；没有列出的 `j` / `k`、`/`、`q` 不应被当成已有能力。

| 上下文 | 当前按键与字符行为 | Esc 的结果 |
| --- | --- | --- |
| ChatInput 与输入补全 | 字符编辑草稿；输入组件解释候选导航和确认 | 按输入与补全的当前状态退出；不自动清空草稿 |
| 命令面板的列表 | 上下或 `k/j` 选择，PageUp/PageDown 分段移动，Home/End 首尾，Enter 执行动作；Space 仅在面板启用时确认；`j/k` 导航，`/` 进入搜索；其余普通字母不自动搜索 | 关闭命令面板 |
| 命令面板的页签 | 页签有焦点时 Tab/Shift+Tab 或左右切换 | 关闭命令面板 |
| 命令面板的搜索框 | 字符与粘贴编辑查询；列表顶部按 ↑、列表或页签按 `/`、或点击搜索框进入；Enter 返回列表，不直接执行条目 | 返回列表，保留查询 |
| Config 的文本编辑 | 字符编辑字段，Enter 提交 | 取消本次编辑，返回设置列表 |
| Keymap 的快捷键录制 | 捕获一次按键或两段组合键，包括普通字母；不执行对应业务命令 | 取消录制，返回快捷键列表 |
| Status 面板 | 上下或 `k/j`、PageUp/PageDown、Home/End 滚动；Tab/Shift+Tab 切页，各页保留滚动位置 | 关闭面板 |
| Session 管理列表 | 上下或 `k/j`、Home/End、PageUp/PageDown 移动；会话动作见下表；字符不写入背景草稿 | 焦点回到输入框 |
| Session 页面预览 | 方向键、PageUp/PageDown、Home/End 和滚轮滚动；`j` / `k` 与下 / 上方向键同义；不接收编辑和粘贴 | 关闭预览并回到原管理列表 |
| 详情浮层 | 上下或 `k/j`、PageUp/PageDown 滚动，Home/End 首尾（也支持 Ctrl+Home/Ctrl+End）；其余按键被消费 | 关闭浮层并恢复原上下文 |
| Queue | 上下或 `k/j`、Home/End、PageUp/PageDown 选择，Enter 恢复编辑，Ctrl+Enter 发送，Ctrl+Up/Down 调序，Delete 删除 | 焦点回到 ChatInput |
| Agents 区 | 上下或 `k/j`、Home/End、PageUp/PageDown 导航，Enter 确认查看的 Thread | 焦点回到 ChatInput |
| 审批和提问的选项 | 上下或 `k/j`、Home/End、PageUp/PageDown 选择，Enter 明确提交；提交中不能重复提交 | 保持待处理状态，不隐式拒绝或回答 |
| 提问的自定义回答 | 字符与粘贴输入答案，Enter 确认 | 取消自定义输入并回到问题选项 |

### Session 管理列表的动作

| 当前项 | Enter | Space | 其他动作 |
| --- | --- | --- | --- |
| 普通会话 | 打开会话 | 打开只读会话预览 | Ctrl+X 归档，`i` 查看元数据详情，`p` 置顶或取消置顶 |
| 所有分组标题 | 切换展开与收起 | 切换展开与收起 | 左收起、右展开；键盘 Enter/Space 与左右展开动作一致 |
| 归档会话 | 取消归档，保留管理页面 | 打开只读会话预览 | Ctrl+X 永久删除整个会话，`i` 查看元数据详情 |

Idle、Working、Failed、Pinned 和 Archived 等分组标题都进入键盘导航，也可点击展开或收起各自的会话列表。Archived 初次默认收起，其余分组默认展开；标题只显示分组名称和完整会话数量，不显示展开或收起符号；键盘当前项使用统一的 `>` 标记。选中标题时提示 `Enter to expand` 或 `Enter to collapse`，折叠后当前项停留在标题，导航跳过隐藏的会话；会话列表刷新保留各组的展开状态。

预览关闭后恢复原列表当前项、分组展开状态、焦点和草稿。预览读取打开时的会话快照，上翻时加载较早历史，不订阅实时输出；再次打开读取最新内容。取消归档恢复主会话的可输入状态，不重新运行已结束的 Turn 或子 agent。

## 统一按键与界面键表

键位先由动作决定，再由当前对象提供具体行为。基础导航在共享 `Navigation` 中解释；命令面板复用 `ListSelection` 的搜索、焦点、确认与退出规则。字母只在列表或只读上下文里作为命令；搜索、文本编辑、自定义回答和快捷键录制先处理自己的输入。不能为了让键表看起来一样而抢走文本字符。

### 共用规则

| 按键 | 列表 / 选择区 | 只读阅读区 | 搜索 / 编辑 / 录制 |
| --- | --- | --- | --- |
| ↑ / k、↓ / j | 上一项、下一项；首尾停止 | 上一行、下一行 | 字母是输入；搜索的方向键可转移焦点，录制中的方向键也作为待录制键 |
| Home / End | 第一项、最后一项 | 已加载内容首尾 | 保留给当前编辑器，不导航背景；当前简单搜索框不支持光标首尾编辑 |
| Ctrl+Home / Ctrl+End | 与 Home / End 同义 | 与 Home / End 同义 | 不操作背景 |
| PageUp / PageDown | 分段移动当前项 | 按当前阅读视口翻页 | 不操作背景 |
| / | 有搜索能力时进入搜索框 | 没有搜索能力时无动作 | 输入 `/`；录制时记录 `/` |
| Enter | 执行当前主动作；页签焦点下进入列表 | 无提交动作 | 搜索返回结果列表；字段编辑保存；自定义回答提交；录制按其阶段记录 |
| Space | 开关类条目切换；会话行预览；具体见下表 | 不自动跳到下一页 | 输入空格；不能同时激活候选 |
| Tab / Shift+Tab | 页签焦点下循环切页；选项焦点下调整当前值；Enter 进入该页列表，↓ 进入搜索或列表 | Status 循环切换页签 | 搜索中不参与导航；编辑和录制由当前组件处理，不穿透到父页签 |
| ← / → | 页签焦点下切页；列表焦点下按条目能力调整值 | Status 无编辑内容，左右也切页 | 不切背景页签 |
| Esc | 返回父面板或输入框 | 关闭当前阅读界面，恢复进入位置 | 搜索回列表且保留查询；编辑或录制取消当前步骤 |

命令列表首项或空列表按 ↑ 进入搜索框，没有搜索框时进入页签；搜索框 ↑ 进入页签，页签 ↓ 进入搜索框，没有搜索框时进入列表。长按方向键不跨区域，松开后再按才转移焦点；列表中的 j/k 到边界停止，不进入搜索框。管理列表、Queue、Agents 和正文条目选择仍在首尾停止，退出使用 Esc。搜索框 ↑ 可进入页签区，↓ 或 Enter 回到列表；按 Enter 返回列表后，还需要再按一次 Enter 才会执行条目。列表与阅读支持长按导航；打开、展开、调整值、切页、提交、恢复、删除和关闭只处理首次 Press，Release 不执行动作。

PageUp/PageDown 的目标统一为快速浏览当前区域，步长由内容决定：普通命令列表与管理列表每次 12 项，正文条目选择每次 12 条，Queue 每次 3 项，Agents 每次 4 项；Status、详情和会话预览使用当时的正文视口行数。阅读中的 ↑/↓/j/k 每次一行；面板滚轮每次移动一项或一行，不改变键盘当前项和焦点。会话预览向上到达已加载内容顶部时请求更早历史；短详情没有历史加载动作。

### 页面、辅助区域与浮层

| 界面 / 进入方式 | 完整操作方案 | 返回方式与必要区别 |
| --- | --- | --- |
| Session / 管理页面的输入框 | 字符编辑草稿；Enter 提交，运行中 Enter 排队、Ctrl+Enter 单次 Steer；Shift+Tab 切权限模式；Ctrl+V 粘贴图片；空输入时左右切页面，管理页 ↑ 进入管理列表，Session 页 ↓ 进入 Agents，Alt+↑ 进入 Queue | 编辑模式与候选状态由输入组件负责；普通字母不作为列表导航 |
| Session 管理列表 | 列表导航；会话 Enter 打开、Space 预览、`i` 详情、`p` 置顶、Ctrl+X 归档；所有分组标题 Enter/Space 切换、左收起右展开；归档行 Enter 恢复、Space 预览、`i` 详情、Ctrl+X 永久删除 | Esc 回输入框；没有 `/` 搜索；各分组独立展开收起，导航跳过隐藏会话 |
| Session 页面预览 | 阅读导航、滚轮；Home 到已加载顶部并可请求更早历史，End 到最新；禁用输入、粘贴和会话修改动作 | Esc 恢复原列表的当前项、展开状态、焦点和草稿；读取快照，不订阅实时输出 |
| 正文条目选择 / 空输入时 Ctrl+↑或Ctrl+↓ | 列表导航；Space 展开可展开内容，Enter 查看完整详情；Ctrl+↑/↓ 保留已有条目选择入口 | Esc 回输入框；Space 展开输出，不承担会话预览 |
| Queue / Alt+↑或点击消息 | 列表导航；Enter 恢复编辑，Ctrl+Enter 立即发送，Ctrl+↑/↓ 调序，Delete 删除 | Esc 回输入框；到边界保持焦点；Ctrl+C 保留中断当前运行的应用动作 |
| Agents / 空输入时 ↓ | 列表导航；Enter 切换所选 Thread | Esc 回输入框；到边界保持焦点，不向草稿输入字母 |
| 审批面板 | 选择导航；Enter 提交所选同意或拒绝；提交中不再响应提交 | Esc 不关闭、不自动拒绝；没有 Space 或单字母同意动作 |
| 提问面板 | 选择导航；Enter 回答当前问题或进入自定义输入；自定义输入接收文字与粘贴，Enter 确认 | 选项状态下 Esc 保持问题；自定义输入中 Esc 取消编辑，回到当前问题 |
| 详情浮层 / 会话 `i` 或正文 Enter | 阅读导航；其他按键不操作背景 | Esc 关闭当前详情并恢复原上下文 |
| 输入补全浮层 / `/`、`@`、`$` | 文字继续编辑查询；方向键选择，Enter/Tab 由候选类型确认；Esc 关闭候选 | 与输入框共同处理编辑；`j/k/空格` 不能当作通用阅读或选择命令 |
| Goal、Plan、TopTip、StatusLine | 展示信息，没有独立键盘焦点或快捷键 | 不为纯展示区域制造单键模式 |
| 终端字符选择 | 鼠标拖选、双击、三击选择；复制使用当前终端/TUI 的复制行为 | 它是文字选择状态，不是新的面板命令上下文 |

输入框本身的字符编辑和 Vim 模式由现有编辑器负责，不能用面板键表重新定义。应用默认键包括 Ctrl+C 中断或退出、空输入 Ctrl+D 中断或退出、Ctrl+O 复制最后回复、Ctrl+Z 挂起；空输入连续 Esc Esc 打开 Rewind。这些仅在路由到应用上下文时可用，不能越过独占的面板、预览或请求处理器。用户配置可以改变应用键位；本节列出的面板基础键当前固定，不通过应用快捷键表重绑。

### 统一程度与设计理由

相同的浏览动作共用键位，长按导航不跨焦点区域。Enter 始终是当前对象的主动作；Space 留给对象的辅助操作，因此开关切换、会话预览和正文展开各有明确对象。Esc 返回一层，搜索查询、父列表当前项与草稿应保留；待回答审批和提问需要明确业务结果，是有意保留的例外。删除保持 Ctrl+X 或 Delete 这样的专门按键，不增加全局 `d`；也不另设全局 `q` 关闭。

新增界面必须先在对应键表中写出入口、当前焦点、导航、主动作、Space、Esc、文本输入和自动重复的含义，再选择共享控件。验收同时检查按键产生的状态与动作、焦点提示、嵌套返回、输入和粘贴隔离、异步完成后的目标身份，以及鼠标和键盘进入同一个业务动作。快捷键已实现但提示未更新、文档列出快捷键但没有事件路径，都视为未完成。

## 交互状态

| 交互事实 | 含义 | 是否改变键盘当前项 |
| --- | --- | --- |
| 焦点 | 当前区域接收键盘输入 | 否 |
| 可操作内容 | 目标拥有打开、展开或提交动作 | 否 |
| 键盘当前项 | Enter、Space 或方向键将作用的目标 | 是 |
| 已生效项 | 当前页签、模式或已经应用的值 | 否 |
| 鼠标悬停 | 指针当前位于可交互目标上 | 否 |
| 鼠标按下 | 左键按下，尚未确定点击或拖动 | 否 |
| 禁用 | 可见但不能操作 | 否 |
| 文字框选 | 选择当前终端帧中的字符 | 否 |

焦点、键盘当前项、已生效项、悬停和按下可以同时存在，不能压成一个状态。鼠标移动不覆盖键盘当前项。具体字符、颜色和无颜色表达由[样式契约](styles.md#交互状态的绘制)统一规定。正文可点击链接的当前缺口见[功能现状](../capabilities.md#明确缺口)。

终端窗口重新获得焦点时只触发一次后台剪贴板图片可用性检查，不转移 TUI 内部焦点，也不修改草稿。检测到图片时，顶部提示显示 `image in clipboard · ctrl+v to paste` 5 秒，重复获得焦点会重新计时，粘贴成功后立即清除；没有图片或检查失败时不显示错误。

每个可交互目标分别保存：所在区域是否有焦点、目标是否已生效或禁用、目标是否为键盘当前项、鼠标是否悬停、鼠标是否按下。功能状态中的成功、警告和失败不属于交互状态，不能代替焦点、选择或悬停。

交互事实如何映射为颜色、标记和文字属性，见[交互状态的绘制](styles.md#交互状态的绘制)。

命令面板中的页签统一复用 `TabListState`：`Tab` 或右方向键切换到下一页，`Shift+Tab` 或左方向键切换到上一页，首尾循环。当内容区也使用左右键调整当前项时，只有页签区获得焦点后才切换页签；选项区的 `Tab` / `Shift+Tab` 与右 / 左方向键一样调整当前项的值；搜索框不处理 Tab / Shift+Tab，左右只移动输入光标。

Status 面板复用统一的页签样式和交互，当前页签通过交互状态的强调样式表达，不在文字中添加方括号。Thread 与 Processes 各自保留 PageUp/PageDown 和 Home/End 的滚动位置。操作提示行显示 `Tab to switch · Esc to close`，不枚举等价的方向键，滚动键继续可用，不重复占用提示行。

## 快捷键声明与保存

默认按键、面板动作名称和 HitBar 组合统一在 `zeta-code/tui/src/keymap/bindings.rs` 声明。`Keybinding` 同时提供按键匹配与提示标签；列表接收具体面板的绑定，导航、搜索、页签、会话管理、审批、提问、队列和正文详情读取同一入口。面板仍拥有焦点、按下与重复事件策略以及动作执行。文字编辑与 Vim 输入语义留在输入组件。

用户覆盖规则继续保存在当前 TUI profile 的 `config.toml`，使用有序的 `[[tui.keybindings]]` 数组，不新增并行 JSON 文件。规则与 `[tui]` 共用设置编辑和 revision 生命周期，TUI 负责命令、条件、顺序与完整候选校验，持久化服务负责 revision 冲突检查。内建声明不写入用户配置，提示文案也不作为用户配置保存。

当前只有应用命令目录中的动作支持用户覆盖；面板绑定已经统一为源码声明，但没有因此开放为 TOML 命令。新增可配置面板动作时，必须同时定义动作身份、焦点条件、冲突规则以及实际绑定对应的提示，不能仅新增一个配置字段。

## 操作提示文案

操作提示随实际焦点变化：列表显示条目动作，页签显示切页和返回列表，搜索显示返回结果列表，编辑与录制显示提交或取消。基础导航（方向键、`j/k`、Home/End、PageUp/PageDown）不常驻操作提示行，按键仍然可用。宽度不足时先省略次要动作，保留完整的 Esc 返回提示；完整键表由本文和 `/help` 承担，不能为了塞满一行而截断关键按键或删除 `to`。

`KeyHints` 与 HitBar 中的操作提示统一写成 `<按键> to <动作>`，按键名使用界面中的标准大小写，例如 `Esc`、`Enter`、`Space` 和 `Ctrl+X`。共享的 `KeyHints` 和 `ListSelection` 接口接收动作本身并统一补上 `to`，调用处不能自行拼接 `Esc close`、`Enter apply` 等文案。

`Esc` 的动作必须按退出后的结果命名：关闭当前临时界面并恢复原上下文用 `Esc to close`；放弃编辑、录制、自定义输入或等待中的组合键用 `Esc to cancel`；从列表选择或 Thread 切换焦点回到聊天输入区用 `Esc to return to input`。`Esc Esc` 表示连续按两次 Esc 的真实快捷键序列，不属于操作提示句式，不改写。

Queue 是 Session 页面里的消息区域，不是命令面板。ChatInput 在 Turn 运行时用 Enter 排队，用 Ctrl-Enter 单次 Steer；Alt-Up 把焦点交给 Queue 最新可编辑项。Queue 获得焦点后必须同时显示 `>` 当前项和 HitBar 键位，Up/Down 选择，Enter 恢复，Ctrl-Enter 立即发送，Ctrl-Up/Down 调序，Delete 删除，Esc 返回 ChatInput；最后一项继续向下保持 Queue 焦点；鼠标单击一行只选中该行，不能改变键盘动作含义。

## 样式映射

本文只决定交互事实与动作。输入提示、键盘当前项、输出标记、颜色值、边线和无颜色终端中的文字属性统一由[样式契约](styles.md)定义；交互实现只能请求对应的语义角色，不能自行选择字符或颜色。

## 鼠标规则

增强 TUI 只控制面板内部的点击、悬停、滚轮、拖选和自动复制。命令面板、审批、提问、详情与补全浮层属于这一范围；终端窗口自身的历史滚动、选择和复制由终端负责。面板键盘导航、搜索、翻页和退出始终可用。没有交互面板或增强开关关闭时释放鼠标捕获。终端协议不能按矩形局部捕获，因此面板打开期间忽略面板外鼠标事件，不把它们路由到背景正文。

TUI 使用终端主屏幕，并在进入时把已有屏幕内容保留到终端历史。关闭鼠标捕获后，滚轮由终端处理，不得转换成面板方向键；VS Code 的 xterm.js 在备用屏幕中会把滚轮转换成方向键，因此不能用备用屏幕承载这一交互契约。退出时保留当前画面并为 shell 留出新行。

已完成的正文按对话顺序完整写入终端回滚区，不按当前视口高度裁剪。流式正文只在当前画面更新；定稿后退出当前画面并写入历史。普通跟随最新画面不再重画已经提交的单元，正文浏览才组合定稿前缀和当前可变尾部。窗口重绘、调整尺寸、主题切换和相同快照重装不会重复提交同一份正文。面板、补全、输入框和状态栏不写入对话历史。恢复旧会话时自动读取所有历史分页，再按从旧到新的顺序输出。终端自身的回滚行数设置决定已经写入的内容能保留多久，TUI 不清空终端回滚区。

鼠标捕获开启时，事件顺序固定如下：

1. 移动只更新悬停目标并请求重绘，不修改键盘焦点、键盘当前项或候选过滤结果。
2. 左键按下记录按下目标并开始区分点击与拖动；按下目标使用按下色。
3. 发生拖动后立即清除按下目标，进入文字框选；拖动过程中不触发页面动作。
4. 左键松开且没有拖动时，只激活松开位置命中的准确目标；是否转移焦点必须是该控件的明确动作，不能由悬停隐式决定。
5. 松开、Resize、页面切换或目标失效时清除按下状态；指针离开可交互目标时清除悬停状态。
6. Enhanced TUI 关闭时，终端拥有鼠标，TUI 不保存悬停、按下或文字框选状态。
7. 指针位于命令面板的选项列表时，滚轮只移动列表视口；搜索框、页签和操作提示不滚动背景列表。Status 与详情在自己的阅读区域滚动。列表的键盘当前项、查询和焦点保持不变，键盘导航重新显示当前项；移出面板或关闭面板后清除悬停、按下和拖选状态。

点击和键盘提交必须进入同一个控件动作，不允许鼠标路径直接执行另一份业务副作用。悬停仅用于呈现；命中测试、键盘当前项和动作映射仍由各组件拥有。

## 所有权与实现约束

组件拥有焦点、当前项、已生效项、禁用和命中结果；应用层拥有当前页面的悬停与按下目标；统一渲染底座接收这些独立事实，并按[样式契约](styles.md)映射为 Ratatui `Style`；主题资源拥有颜色读取、校验和终端色阶转换。命令面板只提供产品内容和动作身份，不能直接使用 Ratatui 固定颜色，也不能把产品结果颜色当成交互颜色。

交互验收至少覆盖：键盘当前项与另一行悬停同时可见、按下与拖动分流、禁用项没有鼠标反馈、已生效 Tab 失焦后仍可识别，以及无颜色终端下不依赖颜色的状态区别。样式验收另外覆盖 Dark、Light、Colorblind 颜色映射、ANSI 色阶转换和固定字符角色。测试使用 Ratatui buffer 中的语义样式和状态断言，不使用截图作为通过依据。

终端历史的已记录验证范围和复现命令统一见[实现手册](../../tui/README.md#终端历史兼容性验证)，不能从本文的行为约定推断所有终端均已验证。
