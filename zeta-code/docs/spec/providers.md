# 供应商、账户与模型

- 入口：`/config → Providers → OpenAI`；模型选择入口为 `/model`。
- 本文记录现行行为要求。多连接与模型目录改造的自动化验收已更新；真实终端和账号未实测，旧面板验收不用于证明新要求，见[OpenAI 变更](../changes/openai-panel/README.md)。
- 认证、配置和模型调用的共享约定见[ChatGPT 订阅](../../../docs/chatgpt-subscription.md)、[供应商配置](../../../docs/model-provider-config.md)和[模型目录](../../../docs/models-manager.md)。

## 页签与字段

| 页签 | 内容与规则 |
| --- | --- |
| Official API key | 官方地址 `https://api.openai.com/v1` 灰色只读，不进入编辑顺序；API Key 使用密码输入 |
| ChatGPT subscription | 账户状态、方案、Sign in、取消和退出；独立于 API Key |
| 每个命名连接 | Provider name、Base URL、API key、API protocol，依次排列，标题在上、控件在下 |
| New custom provider | 始终位于最后；创建后生成并选中新页签 |

- 新连接默认 Responses，也可选择 Chat Completions；现有连接保留原协议。
- 请求严格使用选定协议，不自动探测或切换协议。
- 连接名与内部身份分开；改名不改变凭据归属，不同连接不共享 Key。

## 编辑与保存

| 操作或结果 | 行为 |
| --- | --- |
| 进入表单 | 只选中首个可编辑字段，显示 `>` 指示符；文字与粘贴不修改字段，直到 Enter 进入编辑 |
| 已有连接 Enter | 选中时进入编辑；编辑时确认并保存当前字段；成功后退出编辑，停留在当前字段 |
| 新建连接 Enter | 选中时进入编辑；编辑时只确认字段到草稿并退出编辑；执行创建动作后才保存完整连接 |
| 新建校验 | 名称与合法 Base URL 必填；API Key 可空；不完整草稿不进入供应商列表 |
| 无改动 | 不发送保存请求 |
| 非法值、保存失败、版本冲突 | 显示原因，保留输入与编辑焦点供重试；不覆盖外部修改 |
| Esc | 撤销当前字段本次编辑，再逐层回到页签栏、Providers |
| 移出字段、切换页签或关闭 | 不自动保存；面板内跨页签保留草稿 |
| Tab / Shift+Tab | 遍历表单字段；非编辑状态上下键移动字段，首字段向上进入页签，末操作向下停止 |
| 页签左右键、Alt+左右键 | 页签获焦后左右切换；Alt+左右键可直接切换 |
| 窄终端 | 保持当前字段可见，输入不激活背景；按[终端鼠标规则](terminal.md#鼠标规则)使用键盘 |

## 凭据与持久化

| 数据 | 归属和约束 |
| --- | --- |
| 名称、地址、协议 | 共享配置持久化；保存携带读取时 revision；重启恢复 |
| API Key | 只进入 secret store；空白输入保持原 Key；明文不进入日志、普通配置或字符快照 |
| 未保存字段 | TUI 持有草稿；旧请求不能覆盖新输入 |
| ChatGPT token | 后端拥有；TUI 仅接收账户摘要，不读取 token 或浏览器 Cookie，也不转换为 API Key 计费 |

## 获取与选择模型

| 场景 | 行为 |
| --- | --- |
| Fetch model list | 官方与自定义 API 表单提供入口；主动使用已确认地址、协议和凭据请求 `/models`，不写入配置或凭据；配置 revision 变化时要求重新打开面板 |
| 请求过程 | 开始刷新即清除旧列表；成功显示模型，空列表明确显示失败，其他失败显示认证、权限、不可达等分类原因；失败可重试，已保存连接继续保留 |
| 配置变化 | 地址、协议或 Key 变化后旧目录失效；迟到结果不能恢复旧目录 |
| `/model` | 获取到的模型进入候选；选择后应用对应模型 |
| 重启 | 模型目录属于运行时缓存，可再次主动获取 |
| 成功含义 | 保存配置、获取目录、实际模型调用分别有自己的成功结果，不能相互代替 |

## ChatGPT 账户

| 场景 | 行为 |
| --- | --- |
| 进入账户页 | 读取并显示登录状态和方案 |
| 登录 | 后端决定立即连接还是设备码授权；需要授权时显示验证地址与一次性代码 |
| 等待期间 | 可以取消；返回上层不终止登录，重新进入可以继续查看及取消 |
| 登录结果 | 成功更新状态；失败显示原因供重试；旧账户摘要不能覆盖新状态 |
| 退出或断开 | 由后端按认证管理模式处理并刷新状态；复用模式不退出 Codex 账户，自管模式按共享约定退出 |
| 离开页面 | 完成通知不能重新打开已关闭页面 |
